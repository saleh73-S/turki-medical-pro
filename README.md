# نظام مركز التركي الطبي

واجهة إدارة طبية عربية RTL مبنية باستخدام React وTypeScript وVite. المشروع واجهة مستقلة عن قاعدة البيانات؛ لا يوجد اتصال مفعّل مع Supabase ولا يحتوي على SQL أو مفاتيح سرية.

## التشغيل المحلي

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

لفحص نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## الصفحات

لوحة التحكم، الاستقبال، المرضى، الملفات الطبية، العيادات، المواعيد، الرقود، التمريض، المختبر، الأشعة، الصيدلية، المخزون، المشتريات، نقطة البيع، الصندوق، المحاسبة العامة، القيود اليومية، التقارير المالية والإدارية، الموظفون، الرواتب، المستخدمون والصلاحيات، الإعدادات، وسجل العمليات.

## التصميم المعماري

- `src/data/modules.ts`: تعريف وحدات النظام وبيانات العرض التجريبية.
- `src/components`: هيكل التطبيق والتنقل.
- `src/pages`: لوحة التحكم وصفحات الوحدات.
- `src/lib/supabase.ts`: نقطة إعداد مستقبلية فقط؛ لا تنشئ عميلاً ولا تتصل بخدمة.
- يمكن إعداد متغيرات `VITE_SUPABASE_*` مستقبلاً عبر بيئة الاستضافة، من دون وضع أسرار في الشيفرة. لا تضع مفتاح `service_role` في تطبيق المتصفح.

البيانات المعروضة تجريبية داخل الواجهة وليست سجلات مرضى حقيقية. إنشاء السجلات والبحث يعملان محلياً في حالة الصفحة فقط، ولا تحفظ البيانات بعد إعادة التحميل.

## النشر على Vercel

استورد المستودع في Vercel؛ يتم اكتشاف Vite تلقائياً، وأضفنا `vercel.json` لإعادة توجيه المسارات إلى تطبيق SPA. أمر البناء `npm run build` ومجلد الإخراج `dist`.

## الأجهزة والطباعة

التصميم متجاوب للكمبيوتر واللوحي والهاتف. صفحات الوحدات تتضمن طباعة المتصفح، ويقبل حقل الباركود إدخال قارئ يعمل كلوحة مفاتيح. إعداد الطابعة الفعلي يعتمد على نظام التشغيل والطابعة المتصلة.
